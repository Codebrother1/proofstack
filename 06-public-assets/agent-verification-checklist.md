# Agent Verification Checklist

## Before execution

- [ ] The task has one unambiguous objective.
- [ ] Success is expressed as 3–6 observable, binary criteria.
- [ ] Required evidence is named before the run.
- [ ] Approval gates and prohibited actions are explicit.
- [ ] The exact instruction is preserved.

## After the completion claim

- [ ] The claim and timestamp are preserved verbatim.
- [ ] Each criterion is checked against the actual artifact or state.
- [ ] Tests, diffs, screenshots, files, or state checks are saved.
- [ ] Missing evidence is marked UNVERIFIED.
- [ ] Interventions and retries are counted.
- [ ] The first failure mode is classified consistently.

## Before publication

- [ ] Credentials and personal/client information are removed.
- [ ] Public claims can be traced to dataset rows and evidence.
- [ ] Observations are not presented as universal product statistics.
