# Open-Build Runbook

## Goal

Turn one controlled workflow into a complete ProofStack evidence packet. The fresh work is the integration/test case, not a from-scratch platform.

## Choice order

1. Community task, only if it is appropriately scoped and does not require private credentials.
2. Loaded fallback task prepared in advance.
3. Offline local fixture.

## 60–75 minute sequence

| Time | Action | Artifact |
|---|---|---|
| 0–7 min | Select and bound the task | one-sentence objective |
| 7–15 min | Freeze 3–6 criteria and evidence requirements | task spec |
| 15–32 min | Execute | transcript + state |
| 32–43 min | Verify without repair | criterion report |
| 43–55 min | Repair failed/unverified criteria if needed | second attempt |
| 55–65 min | Reverify and generate report card | evidence packet |
| 65–75 min | Sanitize, push, and prepare the one-minute show | public artifact |

If time compresses, stop after the first verified loop.

## Wrap-up format

> What the person wanted → what the agent did → what verification found → what was repaired → what proves the final result.
