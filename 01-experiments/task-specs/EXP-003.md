# EXP-003 — Cross-Tool: Event Facts to Evidence File

Status: Blocked — live event URL required

## Task

Use Grok Bot to inspect the live event page and create a local Markdown evidence file containing the observable event facts.

## Executor and verifier

- Executor: Grok Bot
- Ground truth: operator compares the output to the live page and saved screenshots

## The task passes only if

1. The output file exists at `03-evidence/EXP-003/attempt-01/event-facts.md`.
2. It records the event name, date, displayed time information, host names, location status, and credit description.
3. If the page contains conflicting schedule information, both values are reported and labeled as a conflict; the bot does not silently choose one.
4. The live source URL and observation timestamp appear in the file.
5. Screenshots preserve the visible facts used.
6. No login, registration change, cancellation, message, or other mutation occurs.

## Exact instruction

```text
Open [PASTE LIVE EVENT URL]. Without signing in or changing the registration, inspect the public event information. Create 03-evidence/EXP-003/attempt-01/event-facts.md containing: event name, date, every displayed time value, host names, location status, and the exact types of credits described. Include the source URL and observation time. If two parts of the page disagree, preserve both values and clearly label the conflict; do not decide which is correct. Save screenshots supporting the report. If any requested fact is not visible, write UNVERIFIED rather than guessing.
```
