# EXP-004 — Repeated Routine: Evidence Folder Starter

Status: Ready

## Task

Teach Grok Bot a routine that creates a correctly named evidence folder and starter notes from three inputs, then repeat it with changed inputs.

## Inputs

- Run A: `EXP-004A`, `Routine baseline`, `Routine`
- Run B: `EXP-004B`, `Routine changed input`, `Routine`

## The task passes only if

1. Each run creates its own `TASK_ID/attempt-01/run-notes.md` folder/file structure in the controlled working directory.
2. Each file contains exactly the supplied task ID, title, category, and creation timestamp.
3. Run B uses the changed inputs and does not copy Run A's task ID or title.
4. Run B does not modify or overwrite Run A.
5. The bot reports the two resulting paths and any error encountered.
6. The operator can inspect both files after the routine completes.

## Demonstration instruction

```text
Learn this routine: given TASK_ID, TITLE, and CATEGORY, create a folder named TASK_ID with an attempt-01 subfolder. Inside it create run-notes.md containing those three supplied values plus the current timestamp. Never overwrite an existing task folder; stop and report a conflict instead. Return the path created and any error.
```

## Execution inputs

```text
Run the learned routine with:
TASK_ID: EXP-004A
TITLE: Routine baseline
CATEGORY: Routine
```

Then:

```text
Run the same learned routine with changed inputs:
TASK_ID: EXP-004B
TITLE: Routine changed input
CATEGORY: Routine
```

## Required evidence

- demonstration transcript
- both execution transcripts
- directory listing
- contents of both Markdown files
