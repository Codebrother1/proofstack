# Evidence Storage

Create one folder per task attempt:

`EXP-###/attempt-01/`

Recommended contents:

- `task-spec.md`
- `exact-instruction.txt`
- `agent-claim.txt`
- `verification.md`
- `terminal-output.txt`
- `diff.patch`
- `before.png`
- `after.png`
- `notes.md`

Do not place credentials, auth tokens, private client data, or personal messages here.
